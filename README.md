# Book a Doctor - Healthcare Booking System

"Book a Doctor" is a full-stack MERN (MongoDB, Express, React, Node.js) web application designed for patients to search and book appointments with doctors, doctors to manage their schedule and consultations, and admins to approve doctors and oversee platform activity.

## Project Structure
- `backend/`: Node.js, Express.js, Mongoose, JWT, bcrypt
- `frontend/`: React.js, React Router, Axios, Bootstrap

## Setup Instructions

### Backend Setup
1. `cd backend`
2. `npm install`
3. Configure `.env` file with your `MONGO_URI` and `JWT_SECRET`.
4. `npm run dev`

### Frontend Setup
1. `cd frontend`
2. `npm install`
3. `npm run dev`
